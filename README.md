Pharmacy Management System

Project Description
A menu-driven Pharmacy Management System developed using the C programming language for the CS-115 Open Ended Lab.

Features
- Add new medicines
- Display all medicines
- Search medicines by name, category, or ID
- Update medicine details
- Delete medicine records
- Sell medicines and generate receipts
- Low-stock alerts
- Generate sales reports
- Save and load records using file handling

Programming Concepts Used
- Structures
- Arrays
- Functions
- Pointers
- Strings
- Loops
- Conditional statements
- File handling
